# Lightcept app icon

The icon uses a dark rounded-square body, standard macOS optical padding, and an `L` formed from a
photo crop-frame corner with a violet exposure wedge.

`lightcept-1024.png` is the production master. `lightcept-dock-512.png` is the runtime icon embedded
by the application, and `lightcept.icns` is used by the macOS bundle. The transparent surround is
preserved so the Dock icon aligns with standard macOS icons.

The `concepts/` directory retains the explored Lightcept variants. See `LICENSE.txt` for licensing.
